Создание секрета использует hard link в том же каталоге, поэтому файловая система должна поддерживать эту операцию. Стандартные локальные каталоги и Docker volumes поддерживают её.

## Ограничения

Автоматические тесты провайдеров используют mock transports. Платные генерации OpenRouter/Qwen, реальный WebRTC-сеанс с микрофоном и запуск всего production-стека Docker не проверялись. Рендер конфигурации Compose не подтверждает запуск контейнеров.

Сборка по-прежнему предупреждает о крупных динамических vendor chunks и отсутствии prerendered-страниц в SPA. Это отдельная задача оптимизации; успешная сборка не измеряет скорость загрузки в браузере. Исправление PWA подтверждено проверкой артефакта, а не реальным offline-сеансом браузера.

После локальной проверки нужен штатный workflow **Quality, Build & Push** на итоговом коммите перед релизом. Последний успешный CI исходной базы: [run 36851385543](https://github.com/Janar0/quip/actions/runs/36851385543). Он не проверял текущее изменение.

## Принятые решения

1. Работа выполнена в новой ветке текущего чистого checkout: зависимости уже были доступны. Цена такого выбора — меньшая изоляция при появлении параллельных пользовательских правок.
2. Исправления, рефакторинг и работа субагентов продолжены по уже данному поручению. Цена ошибки в трактовке объёма — необходимость пересмотреть часть обратимых изменений.
3. Ревью получали снимки изменений, включая новые файлы; Git оставался у контроллера. Цена ошибки — устаревшее ревью, поэтому снимки обновлялись после исправлений.
4. Три обнаруженные в ревью старые гонки task actions/failure cleanup/camera-off включены в исправления. Цена — дополнительные тесты и проверки владения ресурсами.
5. Явные проверки корректности оставлены в voice session даже при превышении ориентировочного размера 650 строк: сначала 667, после финального исправления 672. Цена — немного более длинный модуль.
